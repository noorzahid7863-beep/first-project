# 🤖 Smart AI Hub & Task Workspace

A sleek, production-ready full-stack mobile-first web application featuring AI-powered dynamic chat integration and persistent task management. Built with Next.js, OpenRouter API, and Tailwind CSS.

---

## ✨ Features

- 📱 **Sleek Mobile Frame Layout:** Designed with a modern, responsive mobile chassis UI (Glassmorphic glow, status indicators, dynamic navigation).
- 🧠 **AI Engine & Agents Integration:** Connects seamlessly with OpenRouter API for real-time prompt processing and intelligent responses.
- 📋 **Persistent Task Management:** Full CRUD/status toggling for tasks stored locally (`localStorage`) and synced live across dashboard counters.
- ⚡ **Real-time Status Metrics:** Active task counters and AI model status live updates on the home dashboard.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **AI Integration:** [OpenRouter API](https://openrouter.ai/) (GPT-4o / LLM endpoints)

## 🚀 Getting Started

Follow these steps to run the project locally on your machine:

### 1. Clone the Repository
```bash
git clone [https://github.com/noorzahid7863-beep/first-project.git](https://github.com/noorzahid7863-beep/first-project.git)
cd first-project/my-app

2. Install Dependencies
Bash
npm install
3. Set Up Environment Variables
Create a .env.local file inside the my-app directory and add your OpenRouter API key:

Code snippet
OPENROUTER_API_KEY=your_openrouter_api_key_here
4. Run the Development Server
Bash
npm run dev
Open http://localhost:3000 with your browser to see the result.
